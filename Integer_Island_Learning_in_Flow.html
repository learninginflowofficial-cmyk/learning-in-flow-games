🧭 How to play

  1. Choose a challenge and difficulty.
  2. Read the problem and follow the number line.
  3. Select an answer to earn 10 points.
  4. Use a hint whenever you need one.
  5. Take turns as a class or play individually.

There is no timer or penalty for an incorrect answer. Try again and learn from the steps.

🗺️ Number line guide

Adding a positive: move right →

Adding a negative: move left ←

Subtracting: add the opposite.

Example: 3 − (−2) = 3 + 2 = 5
